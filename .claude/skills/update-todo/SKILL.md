# Updating the todo list

1. Read `ai/todo.md` in full before changing it.
2. Tick off items that were actually completed this session. Don't tick anything that is only partly done; add a short note instead.
3. Add new items only for concrete next steps that came up in this session (e.g. "write the 0.16 debug allocator experiment"). Don't duplicate existing items.
4. Don't reorder or reprioritise the list. What matters most is Tom's call. If an order seems off, ask.
5. Mark items you added with `(AI-added)` so Tom can check them.
6. Show Tom what changed in a short list and ask him to confirm the AI-added items are right.
